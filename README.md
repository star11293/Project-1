## Assignment 1 - Grade Calculator

`GradeCalculator.java` reads a grading setup from `gradeconfig.txt` and a student's scores from `grades_input.txt`. It works out the average for each category, the weighted overall average, and the letter grade (with optional +/- grading). Then it prints a summary and saves it to `grades_report.txt`.

### How to run
1. Put `gradeconfig.txt` and `grades_input.txt` in the same folder the program runs from.
2. Run `GradeCalculator.java`.
3. Type `Y` or `N` when it asks about +/- grading.
